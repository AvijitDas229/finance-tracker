# Contributing Guidelines

Thank you for your interest in improving the Finance Tracker project.  
This document explains how you can contribute in a simple and developer-friendly way.

---

## How to Contribute

1. **Fork the repository**  
   Create your own copy of the project under your GitHub account.

2. **Create a new branch**  
   Use a clear name for your branch (example: `feature/add-new-api` or `fix/mongo-connection`).

3. **Make your changes**  
   Ensure the code is clean, readable, and consistent with the rest of the project.

4. **Test your changes**  
   - Run the development server  
   - Check blockchain interactions  
   - Confirm MongoDB updates  
   - Verify frontend behavior if applicable  

5. **Commit with a meaningful message**  
   Short and clear commit messages help the project stay organized.

6. **Push your branch and open a Pull Request**  
   Describe what you changed and why.  
   If your PR depends on smart contract changes, mention it clearly.

---

## Coding Style

- Keep code simple and readable.  
- Use consistent formatting.  
- Avoid unnecessary files or duplicate logic.  
- Do not commit your `.env` file or any sensitive data.

---

## Pull Request Tips

- Keep PRs focused on one feature or fix.  
- If a PR includes multiple unrelated changes, consider splitting it.  
- Mention if your change requires redeploying smart contracts.  
- If your PR affects backend routes, note how to test them.

---

## Reporting Issues

If you find a bug or want to suggest a feature:

- Open a GitHub Issue  
- Provide a short description  
- Add steps to reproduce (if reporting a bug)

This helps maintainers understand and resolve the issue quickly.

---

## Thank You

Your contributions help make the project better for everyone.  
We appreciate your time, effort, and interest in improving the Finance Tracker.
