# Installation & Configuration Guide

This document provides a complete, step-by-step guide to installing, configuring, and running the Finance Tracker system on your local machine.  
It is written specifically for the technologies used in this repository (Node.js, Express, MongoDB, Truffle, Ganache, Solidity).

---

# 📦 1. Prerequisites

Make sure the following are installed **before continuing**:

### ✔ Node.js (v16 or later)
Download from: https://nodejs.org

### ✔ npm (comes with Node.js)

### ✔ Git
Download from: https://git-scm.com/

### ✔ MongoDB
You may use either:
- **Local MongoDB Community Server**, OR
- **MongoDB Atlas Cloud Cluster**

### ✔ Ganache (Local Ethereum blockchain)
You can use **either** of the following:
- **Ganache CLI**  
  Install using:  
  ```bash
  npm install -g ganache-cli
